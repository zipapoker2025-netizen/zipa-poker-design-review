# ZIPA POKER — 設計系統／VI 會前彙整頁

中華國際德州撲克協會 2026 設計系統討論的內部會前頁。

網頁：https://zipapoker2025-netizen.github.io/zipa-poker-design-review/

`index.html` 自帶樣式與內容，沒有相依套件、不需編譯。內容涵蓋 D01–D12 待拍板決議、色彩系統選項、
語彙紅線表、品牌資產與素材清單、帳號持有人清冊、範本缺口、平台規格與建議討論順序。
設計系統的原始檔與提案來源素材另存於私有 repo。

更新方式：覆蓋 `index.html` 後 push，GitHub Pages 會自動重新部署。
**覆蓋後必須補回結尾的兩行 script 與 head 裡的 robots meta** — 詳見 `CLAUDE.md`。

## 會前表態

- **D01–D12 逐條**：每張決議卡下方都有「同意／有疑慮／先保留」與備註欄。
- **其餘章節整節**：色彩、語彙、資產、帳號、範本、平台等各一組。（資料來源一節不放。）

同事第一次進頁面時留下姓名與通行碼，之後每次點選都會即時送出，右下角顯示自己的進度（例如 `8 / 22`）。
後端連不上時選擇會留在瀏覽器，恢復連線後自動補送。

| 檔案 | 作用 |
|---|---|
| `review-vote.js` | 表態元件，自行掛到決議卡與章節，沿用頁面自己的配色與深色模式 |
| `review-config.js` | 唯一要填 Worker 網址的地方 |
| `results.html` | 彙總頁：逐項統計、誰回覆了什麼、備註原文、CSV 下載，以及一鍵複製「只列未達共識項目」的會議議程 |
| `worker/` | Cloudflare Worker + D1，收集回覆用。部署與維運見 `worker/DEPLOY.md` |

通行碼只用來擋掉不相干的人，不是身分驗證：知道通行碼的人可以用任何姓名送出回覆。
