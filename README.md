# ZIPA POKER — 設計系統審閱頁

中華國際德州撲克協會 2026 視覺識別 **1A 正式協會制式** 的內部審閱頁。

網頁：https://zipapoker2025-netizen.github.io/zipa-poker-design-review/

`index.html` 完全自帶素材（標誌、QR、參考圖皆已內嵌），沒有相依套件、不需編譯。
設計系統的原始檔、範本與提案來源素材另存於私有 repo。

內容：色彩、字體、標誌規則、外部素材與授權、免費體驗賽貼文的兩種解法對照，
以及目前待決的三件事。

更新方式：覆蓋 `index.html` 後 push，GitHub Pages 會自動重新部署。

## 會前表態

每一節下方都有「同意／有疑慮／先保留」與備註欄。同事第一次進頁面時留下姓名與通行碼，
之後每次點選都會即時送出，右下角顯示自己的進度（例如 `4 / 9`）。
後端連不上時選擇會留在瀏覽器，恢復連線後自動補送。

- `review-vote.js` — 表態元件，自行掛到每一節，節次代號取自各節 eyebrow 的英文（例如 `colour`）。
- `review-config.js` — 唯一要填 Worker 網址的地方。
- `results.html` — 彙總頁：逐節統計、誰回覆了什麼、備註原文、CSV 下載，
  以及一鍵複製「只列未達共識節次」的會議議程。
- `worker/` — Cloudflare Worker + D1，收集回覆用。部署步驟見 `worker/DEPLOY.md`。

通行碼只用來擋掉不相干的人，不是身分驗證：知道通行碼的人可以用任何姓名送出回覆。
